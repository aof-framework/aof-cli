# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

The AOF team takes the security of our software and users seriously. If you believe you have discovered a vulnerability or security issue in `aof-cli`, please report it responsibly.

### Disclosure Process

1. **Do not open a public issue** on GitHub for security vulnerabilities.
2. Send an email describing the vulnerability to **security@aof-framework.org** (or use [GitHub Private Vulnerability Reporting](https://github.com/aof-framework/aof-cli/security/advisories/new) if enabled).
3. Include detailed steps to reproduce the issue, sample configuration or command invocations, and any relevant logs or analysis.

### What to Expect

- You will receive an acknowledgment within 48 hours.
- We will work with you to understand and reproduce the issue.
- Once a fix is verified, a patched release will be published alongside an advisory acknowledging your responsible disclosure (unless you prefer anonymity).
